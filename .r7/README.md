# R7 repository context: Frontier-Layout

A static Frontier desktop layout made for a front-end bootcamp exercise, according to `Frontier/README.md`. `Frontier/index.html` contains navigation, a bundle hero, placeholder plan cards, and a modal. `Frontier/assets/scss/` contains Sass source, `Frontier/assets/css/styles.css` is compiled output, `Frontier/assets/js/project.js` opens and closes the modal, and `Frontier/assets/img/` and `Frontier/assets/sketch/` contain visual assets.

`Frontier/package.json` includes a Sass watch command and a placeholder test command. Vendor jQuery and Sass cache files are committed. See [decisions.md](decisions.md) and [December 2017 changes](changes/2017-12.md). The sole default-branch commit is covered.
